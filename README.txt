MY CALENDAR VIEW — personal Chrome extension
=============================================

INSTALL
1. Unzip this file. Keep the "my-calendar-view" folder somewhere permanent
   (e.g. Documents) — Chrome loads it from there.
2. Go to chrome://extensions
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and select the my-calendar-view folder.
5. Pin it: click the puzzle-piece icon in the toolbar → pin "My Calendar View".

CONNECT YOUR CALENDAR
1. Click the extension icon (or press Alt+Shift+C).
2. In Google Calendar: Settings → (left sidebar) your calendar under
   "Settings for my calendars" → "Integrate calendar" →
   copy "Secret address in iCal format".
3. Paste it into the page and click Connect.
   Add more calendars any time from the ⚙ settings.

The secret link is stored only in this browser. Anyone who has it can see
your calendar — if it ever leaks, click "Reset" next to it in Google
Calendar and paste the new one here.

USING IT
- Shows 8 AM to midnight by default (change in ⚙ Settings).
- Events before 8 AM appear in the small "Before 8 AM" row so nothing is missed.
- Click an event for details and an "Open in Google Calendar" button.
- Double-click an empty slot (or "+ New") to create an event in Google Calendar.
- Keys: T today · ← → previous/next · D day · W week · R refresh
- Refreshes every 10 minutes and when you come back to the tab. New events can
  take a few minutes to show up in Google's iCal feed.
- "Account number" in settings = the number after /u/ in your Google Calendar
  address; it makes the Open/Create links use the right Google account.

UPDATING
Replace the files in the folder, then click the reload ↻ icon on the
extension's card in chrome://extensions.
